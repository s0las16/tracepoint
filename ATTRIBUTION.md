# Sample media

Demo excerpts in `public/samples/` are trimmed, silent H.264 derivatives. Audio was removed. `trimStartSec` in `data/sources.json` is how far each excerpt starts into the original. The Commons page is the source of the recording, the license, the artist, the capture time, and any coordinates.

Coordinates in the app are the `prop=coordinates` values returned by the Wikimedia Commons API for that file. Files without coordinates are not mapped. Place names in the labels are shortened from the file description; the full description is stored beside them.
